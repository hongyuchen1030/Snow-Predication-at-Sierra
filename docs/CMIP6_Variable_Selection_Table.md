# CMIP6 Variable Selection Table for WUS-D3 Parent Models

This table keeps each physical variable on a single row. The descriptive columns are compressed into that one row, and the final `Selected` column expands into multiple checkbox lines where pressure-level choices are available.

- Surface-only variables such as `tos`, `tas`, and `psl` stay as one-row, one-checkbox entries.
- Pressure-level atmospheric variables such as `zg`, `ta`, `ua`, `va`, and `hus` stay on one row, with shared pressure options listed only in the final checkbox column.
- Depth-dependent ocean variables such as `thetao`, `uo`, and `vo` stay on one row, but there is **no exact native depth intersection across all four models**, so the row records that limitation instead of inventing a fake shared depth list.
- `MPI-ESM1-2-HR` `ssp370` remains unknown locally; the physical definitions below are verified from historical files.

## Notes

Shared pressure levels verified in all four historical parent models for `zg`, `ta`, `ua`, `va`, and `hus`: `1000, 925, 850, 700, 600, 500, 400, 300, 250, 200, 150, 100, 70, 50, 30, 20, 10, 5, 1 hPa`.

`zg@500 hPa` is selected because it gives the CPM-relevant Z500 field.

`tos` is the clean surface SST field for the AQM / Pacific SST input.

For `thetao`, `uo`, and `vo`, no common native depth exists across all four models; any eventual selection should use a scientifically chosen target depth followed by vertical interpolation.
